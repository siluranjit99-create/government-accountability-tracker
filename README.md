# CivicPulse
CivicPulse is a civilian-driven platform for citizens and community advocates to track and publicise infrastructural issues with public properties and services using photos, locations, and community upvotes to demand accountability from local officials. 


## Tech Stack
| Layer | Technology |
|---|---|
| Structure | HTML5 (semantic) |
| Styling | CSS |
| Interaction | Vanilla JavaScript |
| Automation | Bash |
| Version Ctrl | Git + GitHub |
| Hosting | AWS EC2 |

## Quick Start
```bash
git clone  https://github.com/siluranjit99-create/government-accountability-tracker.git
cd civic-pulse
chmod +x setup.sh && ./setup.sh
```

# Open index.html in your browser

## Features  
- [x] Responsive layout (mobile + desktop)
- [x] Report infrastructural issues in real-time with automatic location tagging and photo uploads
- [x] Engage with community members through upvotes and comments on reported issues
- [x] One-click demo login system allowing guest access without registration 
- [x] Full Git history with PR reviews 
- [x] Dynamic issue tracking status to monitor whether a problem is resolved within days or escalated to severe status
